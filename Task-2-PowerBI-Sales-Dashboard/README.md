# 📊 Superstore Sales Dashboard — Task 2

## Project Overview
An interactive Power BI dashboard built using the Superstore sales dataset to analyze sales trends, profitability, customer segments, product performance, and regional performance.

## Tools Used
- Power BI Desktop
- Superstore Sales Dataset

## Dashboard Features
- Total Sales, Total Profit, Total Orders, and Unique Customers KPIs
- Monthly Sales Trend
- Sales by Product and Category
- Sales by Customer Segment
- Discount vs Profit Analysis
- Region and Segment slicers
