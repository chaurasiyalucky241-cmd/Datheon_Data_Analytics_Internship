# 📊 Superstore Sales Analysis

## 📌 Project Overview
This project analyzes Superstore sales data using Python and Pandas to identify sales trends, evaluate profitability, and understand business performance across product categories, regions, and customer segments.

## 🎯 Objectives
- Analyze total sales and profit.
- Identify monthly sales trends.
- Compare sales and profit across product categories.
- Examine the relationship between discounts and profit.
- Generate data-driven business insights.

## 🛠️ Tools & Technologies
- **Python**
- **Pandas** — Data cleaning and analysis
- **Matplotlib** — Data visualization
- **Jupyter Notebook** — Analysis environment
- **GitHub** — Project documentation and version control

## 📂 Project Files
- `Dartheon_task_1.ipynb` — Python analysis notebook.
- `superstore_sales_clean.csv` — Cleaned dataset.
- `README.md` — Project documentation.

## 🔍 Analysis Performed
1. Data loading and cleaning.
2. Duplicate and missing-value checks.
3. Sales and profit calculations.
4. Monthly sales trend analysis.
5. Category-wise sales and profit comparison.
6. Discount versus profit analysis.
7. Business insights and recommendations.

## 💡 Key Business Questions
- Which product category generates the highest sales?
- Which category contributes the most profit?
- How do sales change over time?
- Is there a relationship between discounts and profitability?
- What insights can help improve business performance?

## 📈 Expected Outcome
The analysis aims to identify important sales trends, profitable product categories, and potential opportunities to improve business performance through data-driven decisions.
